# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through GitHub's private vulnerability reporting:

https://github.com/VoidableUI/Voidable/security/advisories/new

Include the affected package and version, a description of the issue, and steps to reproduce. You will get a response through the advisory thread.

## Supported versions

Fixes are released against the latest published version of each `@voidable/*` package.
