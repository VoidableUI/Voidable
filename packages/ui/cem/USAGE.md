# Generated metadata in `@voidable/ui`

The build writes the Custom Elements Manifest, web-types, VS Code custom data and framework typings into `dist/`. How to use them (editor setup, framework typings, the Angular value accessor) is documented on the docs site: `docs/src/content/docs/guides/editor-setup.mdx`, published as "Editor setup and typings" under Guides.

The build also writes `dist/llms.txt` and `dist/reference.md` (exported as `@voidable/ui/llms.txt` and `@voidable/ui/reference.md`): a short orientation and the full element reference for AI coding agents, generated by `cem/reference.js` from the manifest and the `voidable` tool's examples.
