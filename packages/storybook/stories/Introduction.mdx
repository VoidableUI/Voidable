# Void UI

A component library built on Lit 3 web components with a strict theme-separation architecture.

## Packages

- `@voidable/theme` — CSS custom properties and design tokens
- `@voidable/ui` — Lit web components (Light DOM, zero visual CSS)
- `@voidable/ui-react`, `@voidable/ui-hotwire`, `@voidable/ui-alpine`, `@voidable/ui-liveview` — framework adapters; every other framework is covered by guides and generated typings (see "Frameworks" in the docs)

The component count and the themes are listed on the docs site, not here, so they cannot drift. The Colour scheme, Theme and Skin toolbar menus switch between the shipped schemes, themes and skins.

## Theme Separation

Components in `@voidable/ui` ship with **zero visual CSS**. All styling flows through `--void-*` CSS custom properties defined by `@voidable/theme`.

Without a theme loaded, components are completely unstyled.

## Loading

These stories register every component up front (`import '@voidable/ui'`). In an application you can also import single components, or `@voidable/ui/autoloader` to load each component the first time its tag appears; see "Loading components" in the docs.
