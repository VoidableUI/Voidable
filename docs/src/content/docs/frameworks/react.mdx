The React adapter provides wrapped components with proper ref forwarding and custom event bridging.

## Install

```bash
npm install @voidable/ui @voidable/theme @voidable/ui-react
```

## Usage

Import wrapped components from `@voidable/ui-react`:

```tsx
import { Button, Input, Alert } from '@voidable/ui-react';

function App() {
  return (
    <>
      <Alert color="info">Welcome to Voidable</Alert>
      <Input placeholder="Your name" />
      <Button variant="filled" onVoidClick={() => console.log('clicked')}>
        Submit
      </Button>
    </>
  );
}
```

## Event handling

Voidable components emit `CustomEvent`s (e.g. `void-click`, `void-change`). The React wrappers use `useWcEvents` internally to bridge these to React-style props.

Event props follow the pattern `onVoid{EventName}` in camelCase:

```tsx
<Input onVoidChange={(e) => setValue(e.detail.value)} />
<Dialog onVoidClose={() => setOpen(false)} />
<Switch onVoidChange={(e) => setChecked(e.detail.checked)} />
```

## Theme hook

Track the current theme reactively with `useTheme`:

```tsx
import { useTheme } from '@voidable/ui-react';

function ThemeIndicator() {
  const theme = useTheme(); // 'dark' | 'light'
  return <span>Current theme: {theme}</span>;
}
```

The hook uses `useSyncExternalStore` to observe the `data-theme` attribute on `<html>`, so it works with SSR and concurrent mode.

## Development warnings

A misspelled attribute, a value outside the allowed set or a child in the wrong parent does nothing and says nothing. Import the development entry once, in development only, and the browser console reports each mistake with the element, the valid alternatives and a "did you mean":

```js
if (import.meta.env.DEV) import('@voidable/ui/dev');
```

Put it next to the `import '@voidable/ui'` in `main.tsx`. It checks the elements React renders, because it watches the DOM.

It is never part of `@voidable/ui` itself, so production builds are unchanged. See [Development warnings](/getting-started/development-warnings/) for what it reports and how to make warnings throw in tests.
