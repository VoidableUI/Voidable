`<void-section>` is a titled part of a page: a head, then content. It has no border, no fill and no shadow. What separates one section from the next is space, and that space is the same everywhere because the page sets it.

export const basic = `
<void-section>
  <void-section-head>
    <h2>Upcoming passes</h2>
    <p>Passes assigned to this station in the next 24 hours.</p>
    <void-actions><void-button size="sm">Assign</void-button></void-actions>
  </void-section-head>
  <void-rows>
    <void-row>
      <void-row-text>
        <span>MRD-0412</span>
        <span data-void-type="caption">X band, 9 min 40 s</span>
      </void-row-text>
      <span data-void-type="code">14:02 UTC</span>
    </void-row>
    <void-row>
      <void-row-text>
        <span>MRD-0388</span>
        <span data-void-type="caption">S band, 6 min 12 s</span>
      </void-row-text>
      <span data-void-type="code">14:31 UTC</span>
    </void-row>
  </void-rows>
</void-section>`;

## The head

`<void-section-head>` takes an `<h2>` (or `h3`, `h4`), an optional `<p>` under it, and optionally one thing at the far end: a label, a badge, a state, or `<void-actions>`. A section that needs only a title can use a bare `<h2>` and no head element.

A head is as tall as its text whatever sits at the far end: a button does not make it taller, so the headings of sections with and without an action, and the hairlines of `divided` ones, stay on the same lines. The button is centred on the text and overhangs it by a few pixels above and below. A `ghost` button there (the quiet "View all") has its label on the column's edge; see [Button](/components/button/#at-the-end-of-a-line).

## Divided

Content that draws its own top line (a table, rows, figures, a description list) needs nothing more. Content that does not (the fields of a form, a paragraph, a chart) takes `divided`, which draws a hairline under the head. `gap="stack"` spaces the fields of a form.

<void-section divided gap="stack">

## Side by side

`<void-split>` puts two things in columns that become one column below 48rem. `<void-stack>` stacks things with a named gap.

export const split = `
<void-split ratio="2:1">
  <void-section>
    <h2>Activity</h2>
    <p>The wider column.</p>
  </void-section>
  <void-section>
    <h2>Notes</h2>
    <p>The narrower one.</p>
  </void-section>
</void-split>`;

export const splitErb = `

</void-split>`;

### A column that stays in view

A child with `sticky` stays in view while the column beside it scrolls. It has three states:

- **Bare `sticky`**: sticks on a wide screen and is an ordinary block once the split stacks below 48rem.
- **`sticky="always"`, wide**: the same as bare `sticky`.
- **`sticky="always"`, stacked**: the child stays stuck at the top for the whole length of the split, and the rest scrolls under it. Put it first, so it sits above the list it belongs to. It is painted with the page surface and lies above the content, and it never grows taller than half the screen (`--void-split-sticky-max`, default `50svh`): beyond that it scrolls inside.

A grid item can only stick inside its own row, which is why a stacked split with such a child is laid out as one column of flex items: the child's range is then the whole split. Nothing changes for a split without `sticky="always"`.

export const stuck = `
<void-split ratio="1:2">
  <void-stack sticky="always">
    <img alt="Pass geometry" src="data:image/svg+xml,%3Csvg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 4 3'%3E%3Crect width='4' height='3' fill='%23888'/%3E%3C/svg%3E" style="width: 100%; height: auto; display: block">
  </void-stack>
  <void-rows>
    <void-row><void-row-text><p>Pass 1041</p></void-row-text></void-row>
    <void-row><void-row-text><p>Pass 1042</p></void-row-text></void-row>
    <void-row><void-row-text><p>Pass 1043</p></void-row-text></void-row>
    <void-row><void-row-text><p>Pass 1044</p></void-row-text></void-row>
    <void-row><void-row-text><p>Pass 1045</p></void-row-text></void-row>
    <void-row><void-row-text><p>Pass 1046</p></void-row-text></void-row>

</void-split>`;

The media sits beside the list on a wide screen and stays above it when you narrow the window below 48rem and scroll. When the page has a sticky header, set `--void-split-sticky-top` to its height, on the split or an ancestor, so the child sits below it and not under it; on a wide screen it is added to the group gap.

## Reference

| Element | Attribute | Values |
|---|---|---|
| `void-section` | `divided` | Hairline under the head |
| | `gap` | `inside` (default, 16px), `stack` (24px), `group` (40px) |
| `void-split` | `ratio` | `1:1` (default), `2:1`, `1:2`, `aside` (a 12rem first column, for a settings list) |
| | `valign` | `start` (default), `center`, `end` |
| `void-stack` | `gap` | `tight` 8px, `inside` 16px (default), `stack` 24px, `group` 40px, `section` 72px |
| | `sticky` | As a child of `void-split`: stays in view while the other column scrolls on a wide screen. `sticky="always"` also keeps it stuck at the top when the split stacks |

The attribute is `valign` and not `align` because `align` is an old HTML attribute that browsers still honour on unknown elements: it would also set the text alignment of everything inside.

## Why this form

A section is CSS only: it is a flex column. It is not a card. Voidable's `void-card` and `void-panel` remain for things that are objects (something you can pick up, select or drag); the parts of a page are not objects, and boxing each of them is the fastest way to make a screen heavy.
