Voidable ships {stats.elements} custom elements across {stats.components} components (parent and child elements such as `<void-tabs>` and `<void-tab-panel>` count separately), organized by category. All components render in the Light DOM and are styled entirely through `@voidable/theme` CSS tokens.

## Layout

| Component | Tag | Description |
|-----------|-----|-------------|

| Divider | `<void-divider>` | Visual separator between sections in forms, sidebars, and layouts; supports labels |
| ScrollArea | `<void-scroll-area>` | Fixed-height scrollable container with styled scrollbars for long content and lists |
| NavBar | `<void-nav-bar>` | Top navigation bar for branding, primary links, and user account controls |

## Attributes shared across components

### Booleans that default to true

A boolean attribute normally means true when present and false when absent. A boolean that defaults to true needs a way to say false from markup, so these accept the string `"false"`:

| Component | Attributes |
|-----------|------------|
| `<void-dialog>`, `<void-drawer>` | `closable` |
| `<void-toast>` | `dismissable` |
| `<void-carousel>` | `controls`, `indicators` |
| `<void-nav-bar>` | `bordered` |
| `<void-gauge>` | `show-value`, `tick-min`, `tick-max` |
| `<void-color-picker>` | `show-input` |
| `<void-error-fallback>` | `icon` |
| `<void-input>`, `<void-textarea>`, `<void-action-input>` | `spellcheck` |

```html
<void-toast dismissable="false">Saved</void-toast>
<void-nav-bar bordered="false">...</void-nav-bar>
```

A bare attribute, `="true"` or no attribute all keep the default. Setting the property to `false` from JavaScript works too, and reflects as `"false"`.

### Native text attributes

`<void-input>`, `<void-textarea>` and `<void-action-input>` forward the standard native attributes to their native control: `autocomplete`, `minlength`, `maxlength`, `inputmode`, `enterkeyhint`, `autocapitalize`, `spellcheck`, `readonly`, and (on the single-line inputs) `pattern`. `<void-input>` accepts every text-like `type`: `text`, `email`, `password`, `number`, `tel`, `url`, `search`, `date`, `datetime-local`, `month`, `time` and `week`.

```html
<void-input type="password" name="password" autocomplete="current-password" minlength="8"></void-input>
```

`minlength` and `pattern` take part in validity and form submission. They apply to what the user types, as with a native input.

### Color

Components that take a `color` accept `default`, `error`, `warning`, `success`, `info` and `notice`. Every component whose theme styles it also accepts `caution` (all except `<void-toggle-group>` and `<void-segmented-control>`), and `<void-badge>` and `<void-stat>` accept `highlight`.
