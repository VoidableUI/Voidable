Voidable is a **framework-agnostic web component library** built on [Lit 3](https://lit.dev). Components render in the **Light DOM**, so your children, classes and framework bindings stay where you wrote them and your CSS reaches component internals directly. The one exception is the dialog and the drawer, which keep a small shadow root for the native `<dialog>` they are built on.

## Key features

- **{stats.elements} custom elements** ({stats.components} components) covering layout, forms, data display, feedback, and navigation
- **CSS token system**: {stats.themes} themes and {stats.skins} skins, each in dark and light, switched with `data-void-theme`, `data-void-skin` and `data-theme`, and a [theme builder](/theme/)
- **Zero visual CSS in components** — all styling flows through `@voidable/theme`
- **Current browsers**: the baseline is the Popover API (Chrome and Edge 114, Firefox 125, Safari 17); see [Overlays](/components/overlays/#browser-support)
- **{stats.adapters} framework adapter packages** for React, Hotwire, Alpine, and LiveView, plus guides for Vue, Solid, Svelte, Angular, Lit, Qwik, Astro, and vanilla JS (the first four of those need no package, only configuration and generated typings)

## Quick start

```bash
npm install @voidable/ui @voidable/theme
```

```css
/* Import the full theme in your app entry point */
@import '@voidable/theme';
```

```html
<void-button variant="filled">Click me</void-button>
```

`import '@voidable/ui'` registers every component. To load only the ones a page uses, see [Loading components](/getting-started/loading/).

## Packages

| Package | Description |
|---------|-------------|
| `@voidable/theme` | CSS custom properties and design tokens (`--void-*`) |
| `@voidable/ui` | Lit 3 web components (Light DOM) |
| `@voidable/ui-react` | React wrapper components with event bridging |
| `@voidable/ui-hotwire` | Stimulus controller + Turbo morph protection |
| `@voidable/ui-alpine` | Alpine.js plugin with event directive and Livewire morph protection |
| `@voidable/ui-liveview` | Phoenix LiveView hooks and DOM preservation |
| `live_voidable` (Hex) | Phoenix function components for HEEx templates |
| `voidable-hotwire` (Gem) | Rails helper and asset pipeline integration |
| `voidable/laravel` (Composer) | Laravel service provider for the Alpine/Livewire adapter |
| `voidable` (binary) | The command-line tool: `ref`, `check`, `gen snippet` and an MCP server (`mcp`). Installed with `curl -fsSL https://voidable.dev/install.sh \| sh`, see [For AI agents](/getting-started/for-agents/) |
